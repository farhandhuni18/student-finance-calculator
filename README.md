# Student Finance Calculator

A small, beginner-friendly open-source web tool that helps students estimate monthly income, expenses, and remaining balance in PKR.

## Features
- Enter monthly income
- Add common expense categories
- Calculate total expenses and remaining balance
- Responsive layout for phones and computers
- No account, server, or external library required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter your monthly income and expenses, then select **Calculate budget**.
